# Harness Local 0.4.3 — открытая публикация

Экспериментальный Android-порт DeepSeek Harness для ARM64, без root и отдельного Termux.

Включены вход через аккаунт DeepSeek, OpenAI-compatible провайдеры с инструментами, мобильный интерфейс, SSH и исправление поиска файлов, созданных через write.

В этом релизе архив ядра перенесён с временного Filebin на GitHub Releases. Версия установленного ядра сохранена: обновление APK не требует повторной загрузки ядра. Устанавливайте APK поверх приложения, без удаления и очистки данных.

Файлы релиза:

- `Harness-Local-Mobile.apk` — устанавливаемое приложение.
- `Harness-Local-arm64-preview.zip` — проверяемый архив ядра, скачивается приложением автоматически; вручную устанавливать не нужно.
- `Harness-Local-0.4.3-source.zip` — исходники Android-порта, лицензии и build recipes.
- `SHA256SUMS` — хэши файлов.

Android 9+, ARM64; первая установка требует интернет и минимум 2 ГБ свободного места. Облачные модели оплачиваются у выбранного провайдера. Не все десктопные функции перенесены; см. README.
