# Harness Local 0.4.6 — браузер для агента

Добавлен инструмент `browser`: открытие локального HTML и HTTP(S)-страниц, DOM, нажатия, ввод текста, клавиши, выполнение JavaScript, ошибки консоли и реальные PNG-скриншоты, включая canvas. Используется Android WebView; отдельный браузер скачивать не нужно. Во время проверки держите приложение на переднем плане.

Для передачи скриншотов модели включите «Модели» → «Изменить» → «Модель принимает изображения», если API модели поддерживает изображения, затем сохраните и перезапустите. Текстовые модели получают DOM и консоль, а также путь к сохранённому PNG, но не изображение в контексте.

Устанавливайте APK поверх текущего приложения: подпись и пакет прежние, ядро повторно скачивать не требуется, проекты и настройки сохраняются.

На Android-эмуляторе проверены реальные нажатия и скриншоты трёх режимов тестового canvas, ввод, клавиши, консоль и мобильный/широкий viewport. Проверена передача снимка через upstream MCP image admission и durable image projection с тестовой моделью и хранилищем, без платных API. Полный ARM64-запуск на физическом телефоне здесь не проверялся.
