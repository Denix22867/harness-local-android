# Harness Local 0.4.4 — HTML и файлы из /root

- HTML открывается одним нажатием в дереве файлов Harness, ссылках на файлы в чате и через ⋮ → «Файлы».
- Предпросмотр выполняет JavaScript и загружает соседние ресурсы по относительным путям в отдельном окне. Есть обновление страницы и возврат в Harness.
- «Файлы» и «Экспортировать файл» позволяют выбирать `/workspace` или `/root`, включая проекты в домашней папке.
- Открытие и экспорт учитывают эмулированные hardlink PRoot, которые создаёт инструмент write.

Установите `Harness-Local-Mobile.apk` поверх предыдущей версии. Package ID, подпись и версия большого ядра сохранены: файлы, настройки и аккаунт сохраняются, повторно скачивать ядро не нужно. При новой установке ядро автоматически скачивается из релиза 0.4.3 на GitHub.

Вложения: APK, архив исходников и SHA256SUMS. Android 9+, ARM64. Предпросмотр запускает HTML/CSS/JS; серверная часть на Node/Python автоматически не запускается.
