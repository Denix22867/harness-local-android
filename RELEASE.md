# Harness Local 0.4.7 — скрытый браузер и снимки canvas

Браузер агента теперь работает на отдельном приватном виртуальном экране: чат остаётся видимым и сохраняет фокус ввода. Окно браузера больше не открывается поверх размышлений. Ручной предпросмотр HTML по нажатию остаётся доступен.

Инструмент screenshot автоматически возвращает снимок страницы и отдельные PNG пикселей видимых canvas. Это обход пропуска аппаратного canvas-слоя самим Android WebView; агенту больше не нужно менять игру, вставлять img или уменьшать canvas. Отдельный PNG доказывает содержимое canvas, но не правильное наложение слоёв на страницу. Для передачи изображений модели нужен включённый флажок «Модель принимает изображения» и API с поддержкой изображений.

Проверены большой анимированный canvas 2800×1800, три режима тестового поля, мобильный и широкий viewport, нажатия, ввод, клавиши, консоль, владение сессией, закрытие, сохранение видимого чата и фокуса ввода. Снимки страницы и canvas прошли upstream MCP image admission/projection с тестовыми LLM/attachment service без платных API. Физический Xiaomi и игра пользователя в этой среде не проверялись.

Установите APK поверх текущего приложения. Прежняя подпись, пакет и версия ядра сохранены: повторной загрузки ядра нет, проекты и настройки сохраняются.
